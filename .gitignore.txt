Standardize Backend Filter Logic Across All Modules
User Story:  I want to standardize backend filters across all modules so that filtering is consistent, secure, and performant.
Requirements: Use a common backend filter framework for all modules; Enforce filters only at backend level; Validate and sanitize all filter inputs; Implicitly apply tenant filtering; Implicitly apply RBAC restrictions; Support standard filters including search, status, date range, pagination and sorting; Reject unsupported or invalid filters with clear errors
Acceptance Criteria: All modules use the same filter logic; Filters cannot bypass tenant or role restrictions; No performance regression
